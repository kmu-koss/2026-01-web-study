# 3주차 보고서 예시

## 프로젝트 이름
하츄핑 도감

## 1. 프로젝트 소개
이 프로젝트는 애니메이션 캐릭터인 하츄핑을 시즌별로 정리해서 보여주는 웹사이트입니다. 사용자는 메인 화면에서 하츄핑의 대표 이미지를 보고, 아래 카드 영역에서 시즌별 정보를 선택해서 확인할 수 있습니다. 또한 랜덤 버튼을 눌러 임의의 시즌을 바로 확인할 수도 있습니다.

이 프로젝트는 단순히 이미지를 보여주는 페이지가 아니라, HTML로 화면 구조를 만들고, CSS로 디자인을 적용하고, JavaScript로 버튼 클릭과 카드 선택에 따라 화면 내용이 바뀌도록 만든 웹페이지입니다.

## 2. 프로젝트에서 구현한 기능
- 하츄핑 시즌 1부터 시즌 6까지의 정보를 카드 형태로 표시
- 상단에서 대표 이미지와 현재 선택된 시즌 정보 표시
- 시즌 필터 버튼으로 원하는 시즌만 보기
- 카드 클릭 시 상세 설명 영역 내용 변경
- 랜덤 버튼 클릭 시 임의의 시즌을 선택해서 화면 갱신
- 모바일 화면에서도 볼 수 있도록 반응형 레이아웃 적용

## 3. 사용한 파일

```text
week1/
  index.html
  style.css
  script.js
```

### `index.html`
웹페이지의 뼈대와 내용을 담당합니다. 제목, 설명 문장, 버튼, 상세 정보 영역, 카드가 들어갈 위치가 이 파일에 작성되어 있습니다.

### `style.css`
웹페이지의 색상, 여백, 폰트, 카드 모양, 버튼 스타일, 반응형 레이아웃을 담당합니다. 같은 HTML이라도 CSS가 적용되면 더 보기 좋고 정돈된 화면이 됩니다.

### `script.js`
사용자가 버튼을 누르거나 카드를 클릭했을 때 화면 내용이 바뀌는 동작을 담당합니다. 시즌 데이터도 이 파일 안에 들어 있습니다.

## 4. 파일 사이의 연관 관계
이 프로젝트는 세 파일이 서로 연결되어 작동합니다.

1. `index.html`에서 `<link rel="stylesheet" href="style.css" />`로 CSS 파일을 불러옵니다.
2. `index.html` 마지막 부분에서 `<script src="script.js"></script>`로 JavaScript 파일을 불러옵니다.
3. `script.js`는 `index.html` 안에 있는 `id`와 `class`를 기준으로 필요한 요소를 찾아서 내용을 바꿉니다.
4. `style.css`는 `index.html` 안에 있는 `class` 이름에 맞춰 디자인을 적용합니다.

즉, HTML은 구조, CSS는 디자인, JavaScript는 동작을 담당한다고 볼 수 있습니다.

## 5. HTML 코드가 하는 일
`index.html`은 크게 세 부분으로 나눌 수 있습니다.

### 1) 상단 소개 영역
상단에는 사이트 제목인 `하츄핑 도감`, 소개 문장, 버튼, 핵심 특징 목록이 들어 있습니다. 사용자가 사이트에 들어왔을 때 어떤 사이트인지 바로 이해할 수 있게 만드는 부분입니다.

### 2) 대표 이미지 영역
오른쪽에는 대표 이미지와 현재 선택된 시즌 이름, 무드가 표시됩니다. 이 부분은 처음에는 기본값이 보이지만, 이후 JavaScript가 내용을 바꿉니다.

### 3) 상세 정보와 카드 영역
아래쪽에는 선택한 시즌의 설명, 테마, 마법 도구, 무드, 포인트, 한마디가 표시되는 상세 영역이 있습니다. 또 시즌별 카드가 들어갈 빈 공간도 있는데, 이 카드는 HTML에 미리 전부 적어둔 것이 아니라 JavaScript가 나중에 생성해서 넣습니다.

### HTML에서 같이 알아둔 문법

#### `<!DOCTYPE html>`
이 문장은 "이 문서는 HTML5 문서입니다"라고 브라우저에게 알려주는 역할입니다. 보통 HTML 파일의 첫 줄에 들어갑니다.

#### `<html lang="ko">`
`lang="ko"`는 이 문서의 주 언어가 한국어라는 뜻입니다. 검색, 번역, 접근성 측면에서 도움이 됩니다.

#### `<head>`와 `<body>`
- `<head>`: 브라우저에 전달할 설정 정보가 들어갑니다. 예를 들면 문자 인코딩, 제목, CSS 연결 등이 들어갑니다.
- `<body>`: 실제 화면에 보이는 내용이 들어갑니다.

#### `<meta charset="UTF-8" />`
한글이 깨지지 않도록 문자 인코딩을 UTF-8로 설정하는 코드입니다.

#### `<link rel="stylesheet" href="style.css" />`
이 코드는 HTML과 CSS를 연결합니다.
- `link`: 다른 파일을 연결할 때 사용하는 태그
- `rel="stylesheet"`: 연결하는 파일이 스타일시트라는 뜻
- `href="style.css"`: 연결할 파일 경로

#### 태그와 속성
예를 들어 아래 코드를 보면:

```html
<button id="randomButton" class="primary-button" type="button">랜덤 하츄핑 보기</button>
```

각 부분은 이런 뜻입니다.
- `button`: 버튼 태그
- `id="randomButton"`: 이 버튼 하나만 구별하기 위한 이름
- `class="primary-button"`: 같은 스타일을 적용하기 위한 그룹 이름
- `type="button"`: 이 요소가 버튼이라는 의미
- `랜덤 하츄핑 보기`: 화면에 보이는 글자

즉, HTML 태그는 "무엇을 만들지"를 정하고, 속성은 "그 요소를 어떻게 구분하고 연결할지"를 정합니다.

#### `id`와 `class` 차이
- `id`: 한 페이지에서 보통 하나만 사용하는 고유 이름
- `class`: 여러 요소에 공통으로 붙일 수 있는 이름

이 프로젝트에서는 JavaScript가 `id`로 특정 요소를 찾고, CSS가 `class`로 여러 요소에 같은 디자인을 적용하는 경우가 많습니다.

#### 시맨틱 태그
이 프로젝트에는 `header`, `main`, `section`, `article`, `aside` 같은 태그가 사용됩니다.
- `header`: 상단 소개 영역
- `main`: 핵심 본문
- `section`: 관련 내용 묶음
- `article`: 하나의 독립적인 카드나 설명 블록
- `aside`: 보조 정보 영역

이런 태그를 쓰면 단순히 `div`만 쓰는 것보다 구조를 이해하기 쉬워집니다.

## 6. CSS 코드가 하는 일
`style.css`는 화면을 예쁘게 꾸미는 역할을 합니다.

### 1) 색상 변수 설정
맨 위의 `:root`에서는 자주 쓰는 색을 변수처럼 저장합니다.

예시:

```css
:root {
  --accent: #ff5ca8;
  --ink: #4b2142;
}
```

이렇게 해두면 나중에 버튼색이나 글자색을 한 번에 관리하기 쉽습니다.

### 2) 전체 배경과 기본 글꼴 설정
`body`에서는 페이지 전체 배경색, 글자색, 폰트, 최소 높이 등을 정합니다. 이 프로젝트는 단색 배경이 아니라 그라데이션과 원형 효과를 같이 사용해서 좀 더 화려한 느낌을 줍니다.

### 3) 카드와 버튼 스타일
`.primary-button`, `.ghost-button`, `.card-item` 같은 클래스에서 버튼과 카드의 모양을 만듭니다. 둥근 모서리, 그림자, 마우스를 올렸을 때 살짝 올라가는 효과도 CSS로 구현했습니다.

### 4) 레이아웃 구성
`.hero`, `.overview-grid`, `.card-grid`, `.detail-panel`에서는 `display: grid;`를 사용해 화면을 칸 단위로 배치했습니다. 덕분에 내용이 정돈되어 보입니다.

### 5) 반응형 처리
파일 아래쪽의 `@media` 구문은 화면 너비가 줄어들 때 한 줄에 여러 칸을 배치하던 구조를 한 칸씩 세로로 바꾸는 역할을 합니다. 그래서 휴대폰 화면에서도 비교적 보기 편합니다.

### CSS에서 같이 알아둔 문법

#### 선택자(selector)
CSS는 "어떤 HTML 요소를 꾸밀지" 먼저 정해야 합니다.

예시:

```css
body {
  margin: 0;
}
```

여기서 `body`는 선택자이고, 중괄호 안은 적용할 스타일입니다.

자주 나오는 선택자:
- `body`: 태그 선택자
- `.primary-button`: 클래스 선택자
- `#randomButton`: 아이디 선택자
- `.card-item:hover`: 마우스를 올렸을 때 상태 선택자

#### 속성(property)과 값(value)
아래 코드에서:

```css
color: var(--ink);
```

- `color`: 글자색을 정하는 속성
- `var(--ink)`: 그 속성에 넣는 값

즉 CSS는 `속성: 값;` 형태로 작성합니다.

#### CSS 변수
이 프로젝트는 `:root` 안에 색을 변수처럼 저장합니다.

```css
:root {
  --accent: #ff5ca8;
}
```

그리고 나중에 이렇게 사용합니다.

```css
background: var(--accent);
```

장점은 색을 바꾸고 싶을 때 여러 줄을 일일이 찾지 않고 변수 값만 바꾸면 된다는 점입니다.

#### 박스 모델
HTML 요소는 보이지 않는 상자처럼 생각할 수 있습니다. CSS에서는 이 상자의 크기와 여백을 조절합니다.
- `margin`: 바깥 여백
- `padding`: 안쪽 여백
- `border`: 테두리
- `width`, `height`: 크기

예를 들어 카드가 너무 답답해 보이면 `padding`을 키우고, 카드끼리 너무 붙어 있으면 `margin`이나 `gap`을 조정하면 됩니다.

#### `display: grid`
이 프로젝트에서 많이 사용되는 문법입니다.

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
}
```

뜻은 다음과 같습니다.
- `display: grid;`: 격자 형태로 배치하겠다는 뜻
- `grid-template-columns`: 열 개수와 크기를 정함
- `repeat(3, ...)`: 3칸 반복
- `1fr`: 남은 공간을 비율로 나눠서 차지

즉 카드 3개가 한 줄에 나란히 정렬되도록 만드는 코드입니다.

#### `display: flex`
버튼 정렬이나 가로 배치에도 자주 쓰입니다.

```css
.hero-actions {
  display: flex;
  gap: 14px;
}
```

뜻은 버튼들을 한 줄로 유연하게 배치하고, 사이 간격을 `14px` 주겠다는 뜻입니다.

#### `border-radius`, `box-shadow`, `transition`
- `border-radius`: 모서리를 둥글게 만듦
- `box-shadow`: 그림자 효과
- `transition`: 변화가 부드럽게 보이도록 함

이 세 가지는 버튼과 카드가 "웹사이트처럼 보이게" 만드는 데 자주 쓰이는 기본 문법입니다.

#### `:hover`
마우스를 올렸을 때 상태를 바꾸는 문법입니다.

```css
.primary-button:hover {
  transform: translateY(-2px);
}
```

버튼 위에 마우스를 올리면 약간 위로 움직여서 눌러볼 수 있는 요소라는 느낌을 줍니다.

#### `@media`
화면 크기에 따라 다른 스타일을 주는 문법입니다.

```css
@media (max-width: 980px) {
  .card-grid {
    grid-template-columns: 1fr;
  }
}
```

화면 너비가 980px 이하가 되면 카드 배치를 한 줄 1칸으로 바꾸겠다는 뜻입니다.

## 7. JavaScript 코드가 하는 일
`script.js`는 이 프로젝트의 핵심 동작을 담당합니다.

### 1) 데이터 저장
맨 위의 `seasonEntries` 배열에는 시즌별 제목, 이미지, 설명, 테마, 무드 같은 정보가 객체 형태로 저장되어 있습니다.

즉, 이 프로젝트는 HTML 안에 내용을 하나하나 직접 적기보다 JavaScript에 데이터를 모아두고 필요할 때 화면에 보여주는 방식입니다.

### 2) HTML 요소 찾기
아래 코드에서는 HTML 요소를 가져옵니다.

```js
const filterBar = document.getElementById("filterBar");
const cardGrid = document.getElementById("cardGrid");
const randomButton = document.getElementById("randomButton");
```

이렇게 가져온 요소를 이용해서 나중에 버튼을 만들거나 내용을 바꿉니다.

### 3) 현재 상태 저장
아래 변수는 현재 어떤 필터와 어떤 시즌이 선택되었는지 저장합니다.

```js
let activeFilter = "all";
let activeSeason = "s1";
```

웹페이지가 바뀌는 이유는 사용자의 선택에 따라 이 값이 달라지고, 그에 맞게 다시 화면을 그리기 때문입니다.

### 4) 필터 버튼 만들기
`buildFilters()` 함수는 시즌 목록을 읽어서 버튼을 자동으로 만듭니다. 버튼을 누르면 현재 필터 값을 바꾸고, 다시 카드 목록과 상세 정보를 새로 보여줍니다.

이 방식의 장점은 시즌이 늘어나도 HTML 버튼을 매번 손으로 추가하지 않아도 된다는 점입니다.

### 5) 카드 다시 그리기
`renderCards()` 함수는 현재 필터에 맞는 카드만 골라서 카드 영역에 다시 출력합니다. 카드 HTML도 JavaScript에서 만들어 넣기 때문에, 필터가 바뀌면 카드 목록도 함께 바뀝니다.

또 카드 하나를 클릭하면 `updateDetail()` 함수가 실행되어 대표 이미지와 설명 영역이 새 정보로 바뀝니다.

### 6) 상세 정보 갱신
`updateDetail(entry)` 함수는 선택한 시즌 정보를 받아서 제목, 설명, 테마, 무드, 이미지 등을 한 번에 바꿉니다.

예를 들어 아래와 같은 방식입니다.

```js
detailTitle.textContent = entry.title;
detailDescription.textContent = entry.description;
featuredImage.src = entry.image;
```

즉, 사용자가 카드를 눌렀을 때 화면이 바뀌는 핵심 부분입니다.

### 7) 랜덤 버튼 기능
`pickRandomSeason()` 함수는 시즌 카드 목록 중 하나를 랜덤으로 골라서 현재 선택 상태를 바꾸고, 필터와 상세 정보, 카드 목록을 다시 렌더링합니다.

이 함수는 마지막 줄의 이벤트 코드와 연결됩니다.

```js
randomButton.addEventListener("click", pickRandomSeason);
```

이 코드는 "랜덤 버튼을 클릭하면 `pickRandomSeason` 함수를 실행하라"는 뜻입니다.

### JavaScript에서 같이 알아둔 문법

#### `const`와 `let`
JavaScript에서 값을 저장할 때 사용하는 키워드입니다.

```js
const filterBar = document.getElementById("filterBar");
let activeFilter = "all";
```

- `const`: 한 번 정한 변수 이름에 다른 값을 다시 넣지 않을 때 사용
- `let`: 이후에 값이 바뀔 수 있을 때 사용

이 프로젝트에서는 HTML 요소를 저장할 때는 `const`, 현재 선택 상태처럼 바뀌는 값은 `let`을 사용합니다.

#### 배열(array)
여러 데이터를 순서대로 저장하는 방식입니다.

```js
const seasonEntries = [ ... ];
```

이 프로젝트에서는 시즌 정보 여러 개를 한 묶음으로 저장하기 위해 배열을 사용했습니다.

#### 객체(object)
하나의 대상에 대한 여러 정보를 이름표와 함께 묶는 방식입니다.

예시:

```js
{
  id: "s1",
  label: "시즌 1",
  theme: "하트"
}
```

이 객체는 시즌 1의 여러 정보를 한꺼번에 담고 있습니다.

즉 배열 안에 객체가 여러 개 들어 있는 구조라고 볼 수 있습니다.

#### 함수(function)
반복해서 사용할 동작을 이름 붙여 묶은 것입니다.

```js
function renderCards() {
  ...
}
```

이 프로젝트에서는 필터 버튼 만들기, 카드 그리기, 상세 정보 바꾸기 같은 반복 동작을 함수로 나누었습니다. 이렇게 하면 코드가 정리되고 다시 사용하기 쉽습니다.

#### 메서드(method)
배열이나 문자열, DOM 요소가 가지고 있는 기능입니다.

예를 들어:
- `forEach()`: 배열을 하나씩 반복
- `filter()`: 조건에 맞는 것만 골라서 새 배열 생성
- `find()`: 조건에 맞는 첫 번째 요소 찾기
- `addEventListener()`: 이벤트 연결

이 프로젝트에서는 이런 메서드가 많이 사용됩니다.

#### `forEach`
배열 안의 데이터를 하나씩 꺼내서 반복할 때 사용합니다.

```js
seasonEntries.forEach((entry) => {
  ...
});
```

여기서는 시즌 정보를 하나씩 읽으면서 필터 버튼을 만들고 있습니다.

#### `filter`
조건에 맞는 데이터만 남기고 싶을 때 사용합니다.

```js
const seasonCards = seasonEntries.filter((entry) => entry.id !== "all");
```

뜻은 `id`가 `"all"`이 아닌 데이터만 골라서 새 배열을 만들겠다는 뜻입니다.

#### `find`
특정 조건에 맞는 데이터를 하나 찾을 때 사용합니다.

```js
return seasonCards.find((entry) => entry.id === id) || seasonCards[0];
```

조건에 맞는 시즌을 찾고, 못 찾으면 첫 번째 시즌을 대신 사용하겠다는 뜻입니다.

#### 화살표 함수 `=>`
짧게 함수를 쓰는 문법입니다.

```js
(entry) => entry.id !== "all"
```

이 코드는 "entry 하나를 받아서, 그 id가 all이 아니면 참을 반환한다"는 뜻입니다. `filter`, `forEach`, `find` 같은 메서드와 자주 같이 씁니다.

#### 조건문 `if`
상황에 따라 다르게 동작하게 만드는 문법입니다.

```js
if (activeFilter === "all") {
  return seasonCards;
}
```

현재 필터가 전체이면 전체 카드를 보여주고, 아니면 특정 시즌 카드만 보여주는 식으로 사용됩니다.

#### 문자열 보간법
백틱 `` ` ` `` 을 써서 문자열 안에 값을 넣는 문법입니다.

```js
article.setAttribute("aria-label", `${entry.title} 상세 보기`);
```

`${entry.title}` 부분에 실제 시즌 제목이 들어갑니다. 글자와 변수를 함께 쓸 때 편리합니다.

#### `innerHTML`, `textContent`, `src`
화면 내용을 실제로 바꿀 때 자주 사용합니다.
- `innerHTML`: HTML 구조 자체를 넣을 때 사용
- `textContent`: 글자만 바꿀 때 사용
- `src`: 이미지 주소를 바꿀 때 사용

예를 들어:

```js
detailTitle.textContent = entry.title;
featuredImage.src = entry.image;
```

이 코드는 선택한 시즌에 따라 제목과 이미지를 바꾸는 역할을 합니다.

#### 이벤트(event)
이벤트는 사용자의 행동입니다.
- 클릭
- 키보드 입력
- 마우스 올리기

JavaScript는 이런 행동이 발생했을 때 어떤 함수를 실행할지 연결할 수 있습니다.

```js
randomButton.addEventListener("click", pickRandomSeason);
```

이 코드는 랜덤 버튼이 클릭되면 `pickRandomSeason` 함수를 실행한다는 뜻입니다.

#### DOM
DOM은 브라우저가 HTML을 읽고 만든 문서 구조라고 생각하면 됩니다. JavaScript는 DOM을 통해 HTML 요소를 찾고 수정합니다.

예를 들어:

```js
document.getElementById("detailTitle");
```

이 코드는 HTML에서 `id="detailTitle"`인 요소를 찾아오는 코드입니다.

즉 JavaScript는 DOM을 통해 화면을 조작합니다.

#### 렌더링
렌더링은 화면에 다시 그려서 보여준다는 뜻입니다. 이 프로젝트에서 `renderCards()` 같은 함수 이름은 "카드를 다시 화면에 그린다"는 의미입니다.

그래서 필터가 바뀌거나 카드를 클릭했을 때, JavaScript는 데이터를 바꾼 뒤 화면도 다시 렌더링합니다.

## 8. 실제 코드 예시로 보는 핵심 문법

### 예시 1. HTML 연결

```html
<link rel="stylesheet" href="style.css" />
<script src="script.js"></script>
```

이 코드는 HTML이 CSS와 JS를 불러오는 가장 기본적인 연결 방법입니다.

### 예시 2. CSS 클래스 적용

```html
<button class="primary-button">랜덤 하츄핑 보기</button>
```

```css
.primary-button {
  background: linear-gradient(135deg, var(--accent), #ff86bf);
  color: white;
}
```

HTML에 `class="primary-button"`가 붙어 있으므로 CSS에서 `.primary-button` 스타일이 적용됩니다.

### 예시 3. JS로 요소 찾기

```js
const randomButton = document.getElementById("randomButton");
```

HTML 안의 `id="randomButton"` 요소를 찾아서 변수에 저장하는 코드입니다.

### 예시 4. 버튼 클릭 처리

```js
randomButton.addEventListener("click", pickRandomSeason);
```

클릭이라는 이벤트와 `pickRandomSeason`이라는 함수를 연결한 코드입니다.

### 예시 5. 배열 반복

```js
visibleCards.forEach((entry) => {
  ...
});
```

보여줄 카드 목록을 하나씩 반복하면서 카드 HTML을 생성하는 코드입니다.

### 예시 6. 데이터로 화면 갱신

```js
detailTitle.textContent = entry.title;
detailTheme.textContent = entry.theme;
detailTool.textContent = entry.tool;
```

선택한 시즌 데이터에 들어 있는 값을 실제 화면 글자로 옮겨 적는 코드입니다.

## 9. 이 프로젝트의 동작 흐름
사용자가 페이지를 열면 다음 순서로 실행됩니다.

1. HTML이 먼저 화면의 기본 구조를 만듭니다.
2. CSS가 적용되어 배경, 버튼, 카드 디자인이 입혀집니다.
3. JavaScript가 실행되면서 필터 버튼을 만들고 기본 시즌 정보를 화면에 채웁니다.
4. 사용자가 필터 버튼, 카드, 랜덤 버튼을 누르면 JavaScript가 현재 상태를 바꾸고 필요한 부분만 다시 그립니다.

이 흐름을 이해하면 웹페이지가 "한 번 만들어지고 끝나는 것"이 아니라, 사용자 행동에 따라 화면 일부가 계속 바뀌는 구조라는 점을 알 수 있습니다.

## 10. AI를 활용해 보완했다고 가정한 부분
이 프로젝트를 완성한 뒤 AI와 대화하면서 다음과 같은 부분을 보완했다고 정리할 수 있습니다.

- 시즌 카드에 키보드 입력(`Enter`, `Space`)도 동작하도록 개선
- 카드에 `aria-label`을 넣어 접근성을 조금 더 보완
- 모바일 화면에서 카드와 상세 영역이 한 줄로 쌓이도록 반응형 CSS 추가
- 버튼과 카드에 hover 효과를 넣어 클릭 가능한 요소가 더 잘 보이게 개선
- 시즌 정보를 JavaScript 객체 배열로 정리해서 유지보수가 편하도록 구조 개선

이처럼 AI는 단순히 코드를 대신 써주는 도구가 아니라, 부족한 점을 찾고 왜 그렇게 고쳐야 하는지 설명해주는 보조 도구로 활용할 수 있습니다.

## 11. 어려웠던 점과 배운 점
처음에는 HTML, CSS, JavaScript가 각각 따로 노는 파일처럼 느껴졌지만, 실제로는 하나의 웹페이지를 역할별로 나누어 작성한 것이라는 점을 이해하게 되었습니다.

특히 이번 프로젝트를 통해 다음 내용을 배웠습니다.

- HTML은 화면 구조를 만든다.
- CSS는 화면을 꾸민다.
- JavaScript는 화면을 바꾸고 반응하게 만든다.
- `id`와 `class`가 있어야 CSS와 JavaScript가 HTML 요소를 찾을 수 있다.
- 데이터를 배열과 객체로 정리하면 같은 구조를 반복해서 만들기 편하다.

## 12. 느낀 점
이번 프로젝트는 단순한 소개 페이지보다 조금 더 복잡했지만, 카드 선택에 따라 내용이 바뀌는 구조를 직접 보면서 JavaScript가 왜 필요한지 이해할 수 있었습니다. 또한 CSS의 grid, 버튼 스타일, 반응형 처리까지 함께 보면서 웹페이지를 만들 때 디자인과 기능이 같이 고려된다는 점도 알게 되었습니다.

앞으로 제 프로젝트를 만들 때도 먼저 HTML로 구조를 잡고, CSS로 모양을 정리한 뒤, JavaScript로 필요한 기능을 추가하는 순서로 작업하면 훨씬 정리해서 만들 수 있을 것 같습니다.

## 13. 정리
이 프로젝트는 시즌별 하츄핑 정보를 보여주는 웹사이트이며, `index.html`, `style.css`, `script.js` 세 파일이 서로 연결되어 동작합니다. HTML은 구조, CSS는 디자인, JavaScript는 동작을 담당하며, 세 파일의 역할이 분리되어 있기 때문에 수정과 확장이 쉬워집니다.

이 보고서를 통해 단순히 "만들었다"에서 끝나는 것이 아니라, 내가 만든 웹사이트가 어떤 원리로 움직이는지 설명할 수 있어야 한다는 점이 중요하다고 느꼈습니다.
