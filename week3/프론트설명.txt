3주차 웹 프로젝트 보고서 예시

1. 프로젝트명
하츄핑 도감

2. 프로젝트 개요
본 프로젝트는 애니메이션 캐릭터인 하츄핑을 시즌별로 정리하여 보여주는 웹사이트임.
사용자는 메인 화면에서 대표 이미지를 확인할 수 있으며, 시즌별 카드와 필터 버튼을 이용하여 원하는 정보를 선택해서 볼 수 있음.
또한 랜덤 버튼을 통해 임의의 시즌 정보를 바로 확인할 수 있도록 구성함.

본 프로젝트는 단순 이미지 배치형 페이지가 아니라 HTML, CSS, JavaScript가 각각 역할을 나누어 동작하는 구조로 작성함.
HTML은 화면 구조 작성용으로 사용함.
CSS는 색상, 레이아웃, 버튼, 카드 디자인 적용용으로 사용함.
JavaScript는 버튼 클릭, 카드 선택, 상세 정보 변경 같은 동작 처리용으로 사용함.

3. 구현한 기능
- 시즌 1부터 시즌 6까지의 하츄핑 정보를 카드 형태로 표시함
- 상단 영역에 대표 이미지와 현재 선택된 시즌 정보를 표시함
- 필터 버튼을 눌러 원하는 시즌만 선택해서 볼 수 있게 구현함
- 카드를 클릭하면 상세 설명 영역 내용이 바뀌도록 작성함
- 랜덤 버튼 클릭 시 임의의 시즌이 선택되도록 구현함
- 모바일 화면에서도 확인 가능하도록 반응형 레이아웃을 적용함

4. 사용 파일
본 프로젝트는 총 3개의 핵심 파일로 구성됨.

- index.html
- style.css
- script.js

각 파일의 역할은 다음과 같음.

index.html은 웹페이지의 기본 구조와 내용을 작성한 파일임.
style.css는 웹페이지의 색상, 배치, 크기, 여백, 카드 및 버튼 디자인을 담당하는 파일임.
script.js는 사용자 클릭에 따라 화면 내용이 바뀌도록 처리하는 파일임.

5. 파일 사이의 연관 관계
본 프로젝트는 세 파일이 서로 연결되어 동작함.

index.html에서 style.css를 불러와 디자인을 적용함.
index.html에서 script.js를 불러와 동작 기능을 연결함.
style.css는 HTML 요소의 class를 기준으로 디자인을 적용함.
script.js는 HTML 요소의 id를 기준으로 특정 요소를 찾아 내용을 변경함.

즉 HTML은 구조, CSS는 디자인, JavaScript는 동작을 담당하는 구조임.

6. HTML 코드 설명
HTML은 웹페이지의 뼈대를 만드는 언어임.
이 프로젝트의 HTML은 크게 상단 소개 영역, 대표 이미지 영역, 상세 정보 및 카드 영역으로 나누어짐.

상단 소개 영역에는 사이트 제목, 설명 문장, 버튼, 핵심 특징 목록을 작성함.
대표 이미지 영역에는 현재 선택된 시즌의 이미지와 이름, 분위기를 표시하도록 작성함.
상세 정보 영역에는 시즌 설명, 테마, 마법 도구, 무드, 포인트, 한마디 문구가 출력되도록 작성함.
카드 영역은 JavaScript가 나중에 동적으로 채워 넣을 수 있도록 비워 둔 구조로 작성함.

HTML에서 확인할 수 있는 기본 문법은 다음과 같음.

1) <!DOCTYPE html>
이 문서는 HTML5 형식임을 브라우저에 알려주는 코드임.

2) <html lang="ko">
문서의 주 언어가 한국어임을 의미함.

3) <head> 와 <body>
head는 설정 정보가 들어가는 영역임.
body는 실제 화면에 보이는 내용이 들어가는 영역임.

4) <meta charset="UTF-8" />
한글이 깨지지 않도록 문자 인코딩을 설정하는 코드임.

5) <link rel="stylesheet" href="style.css" />
CSS 파일을 HTML과 연결하는 코드임.

6) <script src="script.js"></script>
JavaScript 파일을 HTML과 연결하는 코드임.

7) 태그와 속성
예를 들어 아래 코드는 버튼 하나를 의미함.

<button id="randomButton" class="primary-button" type="button">랜덤 하츄핑 보기</button>

button는 버튼 태그임.
id는 JavaScript가 특정 요소를 찾기 위해 붙이는 고유 이름임.
class는 CSS가 공통 디자인을 적용하기 위해 붙이는 이름임.
type은 버튼의 종류를 나타내는 속성임.
태그 사이 글자는 실제 화면에 표시되는 문구임.

8) id와 class 차이
id는 한 요소를 구분할 때 사용함.
class는 여러 요소를 같은 그룹으로 묶을 때 사용함.

본 프로젝트에서는 JavaScript가 id를 많이 사용하고, CSS가 class를 많이 사용함.

7. CSS 코드 설명
CSS는 HTML로 만든 구조를 보기 좋게 꾸미는 언어임.
본 프로젝트에서는 배경색, 글자색, 카드 모양, 버튼 스타일, 여백, 반응형 레이아웃을 CSS로 작성함.

주요 문법은 다음과 같음.

1) 선택자
어떤 요소에 스타일을 적용할지 고르는 문법임.

예시
body {
  margin: 0;
}

body는 태그 선택자임.
.primary-button은 클래스 선택자임.
#randomButton은 아이디 선택자임.

2) 속성과 값
CSS는 "속성: 값;" 형태로 작성함.

예시
color: var(--ink);

color는 글자색 속성임.
var(--ink)는 그 값임.

3) CSS 변수
이 프로젝트는 자주 쓰는 색을 변수처럼 저장해서 사용함.

예시
:root {
  --accent: #ff5ca8;
}

이후 background: var(--accent); 와 같이 불러와 사용할 수 있음.
이렇게 작성하면 색을 바꿀 때 관리가 쉬워짐.

4) 박스 모델
HTML 요소는 상자처럼 생각할 수 있음.
margin은 바깥 여백임.
padding은 안쪽 여백임.
border는 테두리임.
width와 height는 크기 지정용임.

5) display: grid
격자 형태로 요소를 정렬하는 문법임.

예시
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
}

카드 3개를 한 줄에 배치하겠다는 의미임.

6) display: flex
버튼처럼 가로 정렬이 필요한 요소에 자주 사용하는 문법임.

예시
.hero-actions {
  display: flex;
  gap: 14px;
}

버튼들을 가로로 정렬하고 간격을 주는 역할을 함.

7) border-radius, box-shadow, transition
border-radius는 모서리를 둥글게 만드는 속성임.
box-shadow는 그림자 효과를 주는 속성임.
transition은 변화가 부드럽게 보이도록 만드는 속성임.

8) :hover
마우스를 올렸을 때 상태가 바뀌도록 하는 선택자임.

예시
.primary-button:hover {
  transform: translateY(-2px);
}

버튼에 마우스를 올리면 살짝 위로 이동하게 작성함.

9) @media
화면 크기에 따라 다른 스타일을 적용하는 문법임.

예시
@media (max-width: 980px) {
  .card-grid {
    grid-template-columns: 1fr;
  }
}

화면이 좁아지면 카드가 세로로 쌓이도록 바뀌게 작성한 코드임.

8. JavaScript 코드 설명
JavaScript는 웹페이지에 동작을 추가하는 언어임.
본 프로젝트에서는 필터 버튼 생성, 카드 출력, 상세 정보 변경, 랜덤 선택 기능을 JavaScript로 작성함.

주요 문법은 다음과 같음.

1) const와 let
변수를 저장할 때 사용하는 키워드임.
const는 한 번 정한 값을 다시 바꾸지 않을 때 사용함.
let은 이후 값이 바뀔 수 있을 때 사용함.

예시
const filterBar = document.getElementById("filterBar");
let activeFilter = "all";

2) 배열
여러 데이터를 순서대로 저장하는 자료형임.

예시
const seasonEntries = [ ... ];

시즌별 정보를 여러 개 저장하기 위해 배열을 사용함.

3) 객체
하나의 대상에 대한 여러 정보를 이름표와 함께 묶는 자료형임.

예시
{
  id: "s1",
  label: "시즌 1",
  theme: "하트"
}

이 구조 하나가 시즌 1의 정보를 뜻함.

4) 함수
반복해서 사용할 동작을 묶은 코드임.

예시
function renderCards() {
  ...
}

카드를 다시 그리는 동작을 함수로 묶어 사용함.

5) forEach
배열 요소를 하나씩 반복하는 메서드임.

예시
seasonEntries.forEach((entry) => {
  ...
});

필터 버튼을 만들 때 시즌 정보를 하나씩 읽기 위해 사용함.

6) filter
조건에 맞는 데이터만 골라내는 메서드임.

예시
const seasonCards = seasonEntries.filter((entry) => entry.id !== "all");

전체 항목을 제외한 실제 시즌 데이터만 남기기 위해 사용함.

7) find
조건에 맞는 하나의 데이터를 찾는 메서드임.

예시
seasonCards.find((entry) => entry.id === id)

선택한 시즌 id와 같은 데이터를 찾는 역할을 함.

8) 화살표 함수
짧게 함수를 작성하는 문법임.

예시
(entry) => entry.id !== "all"

entry 하나를 받아 조건 결과를 반환하는 코드임.

9) if문
조건에 따라 다르게 동작하도록 만드는 문법임.

예시
if (activeFilter === "all") {
  return seasonCards;
}

현재 필터가 전체인지 아닌지에 따라 보여줄 카드 목록을 다르게 처리함.

10) 문자열 보간법
백틱을 사용하여 문자열 안에 변수를 넣는 문법임.

예시
`${entry.title} 상세 보기`

entry.title 값이 실제 문자열 안에 들어가게 됨.

11) DOM
브라우저가 HTML을 읽고 만든 문서 구조를 DOM이라고 함.
JavaScript는 DOM을 이용해 HTML 요소를 찾고 수정함.

예시
document.getElementById("detailTitle")

id가 detailTitle인 요소를 찾는 코드임.

12) textContent, innerHTML, src
화면 내용을 변경할 때 사용하는 속성임.
textContent는 글자 내용만 바꿀 때 사용함.
innerHTML은 HTML 구조 자체를 넣을 때 사용함.
src는 이미지 주소를 바꿀 때 사용함.

예시
detailTitle.textContent = entry.title;
featuredImage.src = entry.image;

13) 이벤트
사용자의 행동을 이벤트라고 함.
클릭, 키보드 입력 등이 이벤트에 해당함.

예시
randomButton.addEventListener("click", pickRandomSeason);

랜덤 버튼 클릭 시 특정 함수를 실행하라는 의미임.

9. 실제 동작 흐름
본 프로젝트의 실행 흐름은 다음과 같음.

1) HTML이 먼저 화면의 기본 구조를 만듦
2) CSS가 적용되어 배경, 카드, 버튼 디자인이 보이게 됨
3) JavaScript가 실행되면서 필터 버튼과 카드가 생성됨
4) 사용자가 버튼이나 카드를 누르면 JavaScript가 현재 상태를 바꾸고 화면 일부를 다시 그림

즉 본 프로젝트는 처음 한 번만 그려지는 정적인 페이지가 아니라, 사용자 입력에 따라 일부 내용이 바뀌는 동적인 페이지라고 볼 수 있음.

10. AI를 활용해 보완한 내용
본 프로젝트를 완성한 뒤 AI와 대화하면서 다음과 같은 부분을 보완했다고 정리할 수 있음.

- 키보드 Enter와 Space로도 카드 선택이 가능하도록 개선함
- aria-label을 추가하여 접근성을 일부 보완함
- 모바일 화면에서 레이아웃이 깨지지 않도록 반응형 CSS를 보완함
- hover 효과를 추가하여 클릭 가능한 요소가 더 잘 보이도록 수정함
- 시즌 데이터를 배열과 객체 구조로 정리하여 유지보수가 쉬운 형태로 개선함

11. 배운 점
이번 프로젝트를 통해 HTML, CSS, JavaScript가 따로 존재하는 것이 아니라 하나의 웹페이지를 역할별로 나누어 작성한 것임을 이해하게 됨.

특히 다음 내용을 배움.

- HTML은 구조 작성용임
- CSS는 디자인 적용용임
- JavaScript는 동작 처리용임
- id와 class는 CSS와 JavaScript가 HTML 요소를 찾는 기준이 됨
- 배열과 객체를 사용하면 반복되는 데이터를 정리하기 쉬워짐
- 함수로 동작을 나누면 코드 관리가 편해짐

12. 결론
본 프로젝트는 시즌별 하츄핑 정보를 보여주는 웹사이트이며, HTML, CSS, JavaScript 세 파일이 서로 연결되어 동작하는 구조로 작성함.
단순히 웹페이지를 만드는 것에서 끝나는 것이 아니라, 각 파일의 역할과 연결 방식, 주요 문법과 작동 원리를 이해하는 것이 중요하다고 판단함.

향후 본인 프로젝트를 설명할 때도 어떤 파일을 사용했는지, 각 파일이 무슨 역할을 하는지, 어떤 코드가 어떤 기능을 담당하는지 정리해서 설명할 필요가 있음.
